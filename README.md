Evangelist is a platform that answers customer questions about a company's products and services—grounded strictly in the company's own documentation, videos, and constraints, rather than general knowledge. 

Cortex is a governed multi-agent framework developed to cater to the above requirements by grounding a Google Vertex AI Agent Builder pipeline in retrieved context.
